# Atelier TensorFlow / Keras — Prédiction de la consommation énergétique

Réseau de neurones (Keras) prédisant la consommation énergétique d'un bâtiment
à partir de la température, l'humidité et le nombre d'occupants.

## Structure
- `notebooks/atelier_tensorflow_iot.ipynb` — atelier complet (Parties 0 à 11)
- `models/modele_consommation.keras` — modèle entraîné et sauvegardé

## Lancer
```bash
pip install tensorflow matplotlib numpy scikit-learn
jupyter notebook notebooks/atelier_tensorflow_iot.ipynb
```
